# Requirements

What AutoFlow needs to run:

- Claude Code v2.1.277+
- `git`
- `jq`
- the GitHub CLI `gh`
- the Codex CLI `codex`, for the default reviewers (no reviewer named in `~/.autoflow/config.json`; [`reviewer-backend.md`](reviewer-backend.md))
- a GitHub repository (one per sub-repo, for a project with sub-repos)
